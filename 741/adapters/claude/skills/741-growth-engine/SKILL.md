# 741 Growth Engine for Claude

Apply `741/core/skills/growth-engine/SKILL.md` and `741/core/orchestration/P1-GROWTH-MARKETING-CONTRACT.md`.

## Claude execution

1. Define decision, hypothesis, scope, variants, primary metric and decision rule before evaluating results.
2. Use connected tools/files as evidence sources only; preserve provenance and date range.
3. Distinguish planned tests, simulated judgments and observed outcomes.
4. For `planned` or `running` experiments without final observed evidence, use `result: not_evaluated`; do not use `UNKNOWN` as a substitute for lifecycle state.
5. Do not state that completed experiments equal zero unless an authoritative source establishes zero; when supplied data contains no completed experiment evidence, state that explicitly.
6. Consume authoritative Revenue Intelligence findings when funnel/revenue/GP/attribution is relevant.
7. Never rewrite Sales Pipeline scoring from experiment results without explicit review.
8. External launches, writes, publishes or mutations require the applicable approval gate.
