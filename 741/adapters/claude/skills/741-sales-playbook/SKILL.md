# 741 Sales Playbook for Claude

Apply `741/core/skills/sales-playbook/SKILL.md` as the canonical workflow.

Use available Claude tools, MCP integrations, project files, transcripts, CRM/email/calendar sources, and web research to gather evidence. Clearly separate verified facts, hypotheses, and discovery questions.

Drafting does not authorize sending. CRM/calendar/email mutations follow `741/core/policies/ACTION_APPROVAL_POLICY.md`.

For WLP opportunities, use the WLP knowledge layer and prepare discovery around trade lane, cargo, mode, bonded storage, inventory/fulfillment, volume, service level, documentation, and regional distribution requirements.

## Evidence guardrails

- Preserve the official Sales Pipeline scorecard as frozen when supplied. Do not create or alter qualification evidence owned by Sales Pipeline.
- Do not present a prospect's logistics-network membership, shared network with WLP, prior relationship, incumbent provider, decision-maker identity, sender identity, or referral path as fact without explicit supporting evidence.
- Network names may appear in discovery questions as examples only when clearly labeled as examples, not as known prospect facts.
- Do not invent pricing, discounts, volume commitments, ROI, savings, capacity, transit times, or commercial terms.
- If the user requests an exact number of discovery questions, objections, packages, or variants, return exactly that number unless safety prevents it.
