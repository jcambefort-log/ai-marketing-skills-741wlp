# 741 P1 Growth & Marketing Orchestration Contract

## Scope

This contract coordinates five P1 skills:

1. 741 Growth Engine
2. 741 Content Quality
3. 741 SEO Intelligence
4. 741 Conversion Intelligence
5. 741 Deck Builder

It supplements, not replaces, the validated P0 commercial contract.

## Authority map

| Domain | Authority |
|---|---|
| Controlled experiments, test learning, promote/keep-testing/discard | 741 Growth Engine |
| Artifact quality scoring and revision | 741 Content Quality |
| SEO/AEO/GEO opportunity discovery and search readback | 741 SEO Intelligence |
| Website/landing-page conversion diagnostics | 741 Conversion Intelligence |
| Presentation narrative and slide architecture | 741 Deck Builder |
| Official WLP prospect scoring | 741 Sales Pipeline |
| Outbound readiness/sequence/launch planning | 741 Outbound Engine |
| Discovery/positioning/proposal/negotiation prep | 741 Sales Playbook |
| Observed pipeline/revenue/GP/attribution | 741 Revenue Intelligence |
| WLP pricing/financial protection | WLP Financial Sentinel |
| WLP commercial voice | WLP Commercial Partner |
| WLP organizational coherence | WLP Org Guardian |
| WLP brand execution | WLP Brand Expert |
| Strategic hypothesis/decision learning | Double Loop Personal WLP |

## Core precedence rules

1. Current authorized evidence overrides dated snapshots.
2. Domain owners control their authoritative fields.
3. Downstream skills may consume authoritative outputs but may not silently rewrite them.
4. UNKNOWN remains UNKNOWN.
5. Plans, simulated reviews and recommendations are not observed events.
6. Connected capabilities do not authorize external actions.
7. External writes, sends, publishes, launches, pricing commitments and destructive actions require the applicable approval policy.

## Standard flows

### Search-to-revenue loop

`SEO Intelligence → Content Quality → Brand/Commercial authority → Conversion Intelligence → Growth Engine → Revenue Intelligence`

### Outbound experimentation loop

`Sales Pipeline → Outbound Engine → Content Quality → Growth Engine → Revenue Intelligence`

Growth Engine must consume the frozen Sales Pipeline scorecard when prospect scoring is relevant and must never recalculate it.

### Website optimization loop

`SEO Intelligence → Conversion Intelligence → Content Quality → approved implementation → Growth Engine/readback → Revenue Intelligence`

### Presentation loop

`authoritative evidence → Deck Builder → Content Quality → WLP Brand Expert → presentation renderer`

### Strategic-capacity loop

`Revenue Intelligence + Financial Sentinel + Org Guardian → Double Loop → Deck Builder`

Deck Builder presents the decision case; it does not decide financial or organizational policy.

## Anti-overlap rules

- Content Quality scores are not conversion, revenue or experiment outcomes.
- SEO rankings are not revenue attribution.
- Conversion heuristics are not observed conversion rates.
- Growth experiments do not change ICP/scoring models without explicit review.
- Deck Builder does not create financial assumptions to fill slide gaps.
- WLP Brand Expert remains the brand authority even when Content Quality evaluates readability or consistency.

## Activation rule

Use the minimum set of skills needed for the user's task. Do not activate all P0/P1 skills by default.

## Validation requirement

Each P1 skill must pass:

`install → functional test → audit → correct if materially needed → retest → approve`

Cross-skill validation must confirm authority separation, UNKNOWN preservation, source provenance and action approval boundaries.
